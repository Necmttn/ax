## Gate findings (orchestrator, beyond pane reports)

- fix-runtime-guards: the `wx` claim file had no staleness recovery - a
  SIGKILL between claim and release would disable the freshness drive
  forever (`Effect.ensuring` cannot run on process death). Added a 10-minute
  stale-claim reclaim + two tests at the gate.
- fix-pricing-core x segment: #966 moved turn cost columns into
  `ENRICHMENT_COLUMNS`, which strips them from segment export - the segment
  contract tests pinned the old "turn costs RIDE" decision and broke
  repo-wide `bun test` on main. Retracted in place (#967): importer re-derive
  prices against the local catalog (the same PR extended the backfill to turn
  rows, closing the loop).
- fix-dedupe-sig residual (accepted): `cites_evidence` cache edges keep old
  proposal ids for pre-migration agent-origin proposals; decisions intact.
- cost-query.ts carries a pre-existing literal NUL byte in a map-key template
  string, so git diffs it as binary; not introduced by this run.
